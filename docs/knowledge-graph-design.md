# 笔记与习题知识图谱设计

日期：2026-10-24

## 已确认的产品约束

- 一篇笔记就是一个考点，由内容作者拆分笔记；不增加独立的 concepts 层。
- 关联只在 Markdown frontmatter 中维护，使用稳定 ID，数据库保存可重新生成的关联索引。
- 题目的 `notes: [note-id, ...]` 表示考查哪些笔记，支持多对多。笔记侧自动反查关联习题。
- 笔记的 `references: [note-id, ...]` 表示引用其他笔记，保留方向；被引用笔记自动显示反向链接。
- 阅读笔记和做题时显示一跳局部图谱。每个科目另有独立图谱页面，默认只展示笔记和引用关系，选中笔记后可展开关联习题。
- 做题时通过侧边抽屉阅读笔记，保留当前题目、未提交答案和练习进度；移动端抽屉占满屏幕。

## 技术选择

保留 Vue、Hono、D1 和现有 Git 内容同步流程。图谱使用 Cytoscape.js，业务关联、API 与阅读交互在本项目实现。Quartz 作为局部图谱与反向链接体验的参考，不引入第二套网站构建和路由系统。

## 内容格式

```yaml
# content/notes/...md
id: note.math1.cauchy-mean-value
topic: math1.mean-value
title: 柯西中值定理
references:
  - note.math1.lagrange-mean-value
```

```yaml
# content/questions/...md
id: math1.mean-value.001
notes:
  - note.math1.cauchy-mean-value
  - note.math1.lagrange-mean-value
```

两个字段均为可选的 ID 数组，省略表示没有关联。校验器拒绝错误类型、重复 ID、未知 ID、自引用；允许不同笔记之间形成引用环。正文 `:::question` 保留为例题跳转，不隐式生成考查关系。知识关联以 frontmatter 为准。

## 数据与同步

新增两张表，均使用复合主键、外键和反向查询索引：

- `question_notes(question_id, note_id)`。
- `note_references(source_note_id, target_note_id)`。

原有 topic 树继续作为目录，题目的 topic 分类和考点笔记关联分别维护。同章节归属不自动生成考查关系。

先同步笔记与题目实体，再替换关联索引；删除 frontmatter 条目会移除对应边，删除内容会归档实体并清除相关边。同步过程应确保重跑幂等，关联变动参与内容哈希。引用、被引用和图谱只返回有效内容。

## API 与图谱范围

- 笔记详情 API：返回正文、引用、被引用、关联题目摘要和所属科目。
- 题目关联笔记 API：供做题页加载考点入口；不包含答案与解析。
- 局部图谱 API：以笔记或题目为中心，返回一跳节点与有向边。
- 科目图谱 API：通过 topic 的父子关系确定科目和章节范围，不依赖 ID 前缀。默认仅返回笔记；展开指定笔记时加入其习题节点和考查关系。跨科引用在局部图谱与笔记链接中可见，科目图谱仅展示本科目笔记。
- 全部 API 沿用现有登录保护，图谱节点使用带实体类型的 ID，避免笔记和题目同名冲突。

## 页面与交互

- 笔记支持可复制的独立地址，章节列表可进入单篇阅读。
- 笔记详情展示引用、反向链接、关联习题与局部图谱；点击习题创建该题的练习会话。
- 做题页展示考点入口和局部图谱；点击笔记打开抽屉，抽屉内可继续阅读引用笔记、返回上一笔记。
- 抽屉支持 Escape、焦点约束、关闭后恢复焦点；打开时暂停做题快捷键。
- 科目图谱支持科目切换、搜索、章节筛选、选中节点详情和按需展开习题。提供文本链接列表作为键盘和辅助技术入口。
- 图谱组件只处理布局与交互，阅读抽屉和练习会话负责业务操作；打开或关闭抽屉不重新加载当前练习条目。

## 实施与验证

1. 数据迁移、frontmatter 校验、关联索引同步与样例内容。
2. 受保护的笔记详情、关联查询和图谱 API。
3. 独立笔记阅读、双向跳转和做题侧边抽屉。
4. Cytoscape.js 局部图谱和独立科目图谱页。
5. 校验和同步回归、API 方向与范围及答案隔离测试、浏览器验证抽屉不丢失答案和快捷键隔离、科目图谱默认仅笔记并可展开习题。

本次实施限于本地仓库与本地验证，不需要变更线上部署。
